# RecSys Evaluation Bot

Асинхронный Telegram-бот для автоматического тестирования сервисов рекомендаций.
Бот собирает необходимые параметры от студента, проверяет работоспособность
сервиса и проводит нагрузочное тестирование с заданным RPS, после чего выставляет
финальные ML-метрики (Precision/Recall). Все результаты логируются в публичную
Google-таблицу и локальную базу данных SQLite.

## Зависимости и Стек

- [uv](https://github.com/astral-sh/uv) (современный и быстрый пакетный менеджер для Python)
- Docker & Docker Compose
- `aiogram` v3 (фреймворк для бота)
- `aiogram-sqlite-storage` (персистентное хранение состояний FSM)
- `aiosqlite` (асинхронная работа с БД SQLite)
- `aiohttp` (тестирование API и нагрузка)
- `pandas` (расчет метрик)
- `gspread` (интеграция с Google Sheets)

## Хранение Данных и Персистентность

Бот полностью сохраняет состояние диалогов и параметры конфигурации.
Даже после перезапуска сервиса:

1. **FSM (Состояние)**: Бот "вспомнит", на каком этапе ввода данных вы остановились.
2. **Конфигурация**: Параметры сервиса (@ник, URL, Модель) сохраняются в БД. При повторном `/start` бот предложит использовать ранее введенные данные.
3. **Результаты**: Все успешные и неуспешные прогоны записываются в таблицу `test_results` с метриками и временем выполнения (`duration`).

Все данные хранятся в файле `data/recsys_bot.db`.

## Подготовка данных (`test.csv`)

Файл `test.csv` должен лежать в корне проекта. Он используется для генерации запросов к вашему сервису.

### Формат данных

CSV с запятой (`,`) и колонками:

1. `user_id` (integer)
2. `item_id` (integer) — ground truth.

Пример:

```csv
user_id,item_id
1023,551
1023,12
4551,33
```

## Настройка Окружения (`.env`)

Создайте файл `.env` в корне проекта (на базе `.env.example`).

```env
BOT_TOKEN=your_token
DATABASE_PATH=data/recsys_bot.db
GOOGLE_SHEET_URL=...
GOOGLE_CREDS_JSON=...
```

## Инструкция по запуску

### 1. Подготовка (единоразово)

Убедитесь, что у вас установлен `uv`. Затем выполните:

```bash
make setup
```

### 2. Запуск

#### Вариант А: Локально (для разработки)

```bash
make run
```

*Команда автоматически создаст папку `data/` и применит изменения в БД.*

#### Вариант Б: Через Docker (Production)

Для развертывания на удаленном сервере (VPS/Cloud) рекомендуется использовать Docker. Это обеспечит стабильную работу и автоматический перезапуск бота.

---

## Развертывание на сервере (Linux)

### 1. Подготовка сервера

1. **Приобретите VPS/VDS**: подойдет любой провайдер (Selectel, Timeweb, DigitalOcean и др.).
   - Рекомендуемая конфигурация: **1 vCPU, 2 ГБ RAM**.
   - ОС: **Ubuntu 22.04 LTS** (или новее).
2. **Обновите пакеты**:

   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

3. **Установите Docker**:

   ```bash
   curl -fsSL https://get.docker.com -o get-docker.sh
   sudo sh get-docker.sh
   ```

### 2. Клонирование и настройка

```bash
git clone https://github.com/qw1zzard/recsys-evaluation-bot.git
cd recsys-evaluation-bot
```

1. **Конфигурация**: Создайте `.env` и `service_account.json` (ключ Google Cloud) в корне проекта.
2. **Данные**: Убедитесь, что файл `test.csv` загружен в корень.

### 3. Запуск

```bash
docker compose up -d --build
```

**Полезные команды:**

- `docker compose logs -f` — просмотр логов в реальном времени.
- `docker compose stop` — остановка бота.
- `docker compose up -d` — запуск (после остановки или изменения `.env`).

---

## Нюансы и Полезные Команды

- **Сброс Базы**: Чтобы начать "с чистого листа", просто удалите файл `data/recsys_bot.db`.
- **Google Sheets**: Не забудьте выдать права **Editor** на вашу таблицу для email из `service_account.json`.
- **Логи**: Все прогоны логируются в консоль. Ищите строки `Test result saved for user X`.
- **Автозапуск**: Благодаря `restart: unless-stopped` в `docker-compose.yml`, бот будет автоматически подниматься после перезагрузки сервера.

### Как проверить, что все работает?

1. Отправьте `/start` боту.
2. Введите параметры своего сервиса.
3. Если после перезапуска бота он сразу показывает меню "🚀 Запустить тест" вместо приветствия — персистентность работает!
